DATAVORA — Project Handoff

1. Project Information

Project Name: DATAVORA
Tagline: Turn Data Into Decisions.
Project Type: Industrial Training Project
Domain: Data Analytics and Business Intelligence

2. Project Objective

Develop a universal analytics platform that allows users to upload Excel and CSV datasets, clean data, perform exploratory analysis, generate interactive visualisations and obtain meaningful business insights.

3. Technology Stack

* Python
* Streamlit
* Pandas and NumPy
* Plotly, Matplotlib and Seaborn
* Scikit-learn
* SQLite
* Power BI
* Git and GitHub

7. How to Run the Project

Activate the environment:

source .venv/bin/activate

Install dependencies:

pip install -r requirements.txt

Run the application:

streamlit run app.py
