DATAVORA

Turn Data Into Decisions

Development of DATAVORA – A Universal Data Analytics and Business Intelligence Platform Using Python and Power BI

1. Project Overview

DATAVORA is a universal data analytics and business intelligence platform designed to help users analyse datasets without requiring advanced technical knowledge.

Users can upload Excel and CSV files, perform automated data cleaning, explore statistical information, generate interactive visualisations, and obtain meaningful insights from their data.

2. Objectives

* Support Excel and CSV dataset uploads.
* Identify data types and dataset characteristics.
* Perform automated data cleaning.
* Generate exploratory data analysis (EDA).
* Recommend suitable interactive visualisations.
* Generate automated analytical insights.
* Provide advanced analytics where appropriate.
* Export cleaned datasets and analytical reports.
* Support integration with Microsoft Power BI.

5. Installation and Execution

Clone the repository:

git clone https://github.com/Mansimar90/DATAVORA.git
cd DATAVORA

Create and activate a virtual environment:

python3 -m venv .venv
source .venv/bin/activate

Install dependencies:

pip install -r requirements.txt

Run the application:

streamlit run app.py
